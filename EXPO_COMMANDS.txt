================================================================================
          DATA UDIPI MOBILE APP - EXPO & EAS COMMANDS REFERENCE GUIDE
================================================================================
Location: Mobileapp_frontend
Backend Target: https://dev-api.dataudipi.com

--------------------------------------------------------------------------------
1. DEVELOPMENT & EXPO GO COMMANDS
--------------------------------------------------------------------------------

# 1.1 Start Expo Development Server (Standard)
npx expo start

# 1.2 Start Expo Server with Cache Cleared (Fixes stale bundle issues)
npx expo start -c

# 1.3 Start Expo in LAN Mode (For devices on the same Wi-Fi network)
npx expo start --lan

# 1.4 Start Expo in Tunnel Mode (For testing over mobile data / different networks)
npx expo start --tunnel

# 1.5 Run Web Version in Browser
npx expo start --web

# 1.6 Run on Connected Android Device or Emulator directly
npx expo run:android

# 1.7 Run on iOS Simulator (macOS only)
npx expo run:ios

# 1.8 TypeScript Static Verification (Check for compile/type errors)
npx tsc --noEmit


--------------------------------------------------------------------------------
2. DEVELOPMENT CLIENT (FOR CUSTOM WEBRTC & VAPI VOICE AGENT)
--------------------------------------------------------------------------------
Note: Native WebRTC / Vapi voice features require custom native code and will not 
run inside the generic Expo Go app store client.

# 2.1 Build Custom Android Dev Client (via EAS Cloud)
eas build --platform android --profile development

# 2.2 Build Custom Android Dev Client Locally (Requires Android SDK)
eas build --platform android --profile development --local

# 2.3 Run Custom Dev Client after installing APK
npx expo start --dev-client


--------------------------------------------------------------------------------
3. EAS CLOUD BUILD COMMANDS
--------------------------------------------------------------------------------

# 3.1 Installable Preview APK (For Physical Device Testing / Internal QA)
# Generates a standalone .apk that anyone can download and install directly on Android.
eas build --platform android --profile preview

# 3.2 Production App Bundle (For Google Play Store Release)
# Generates a signed .aab bundle ready for upload to Google Play Console.
eas build --platform android --profile production

# 3.3 iOS Production Build (Requires Apple Developer Account)
eas build --platform ios --profile production

# 3.4 Multi-Platform Production Build (Android + iOS simultaneously)
eas build --platform all --profile production


--------------------------------------------------------------------------------
4. LOCAL STANDALONE BUILDS (OFFLINE / VIA LOCAL GRADLE & ANDROID SDK)
--------------------------------------------------------------------------------

# 4.1 Generate Native Android Project Folder
npx expo prebuild --platform android --clean

# 4.2 Build Release APK Locally via Gradle
cd android
./gradlew assembleRelease
cd ..
# Output APK: android/app/build/outputs/apk/release/app-release.apk

# 4.3 Build Release Bundle (AAB) Locally via Gradle
cd android
./gradlew bundleRelease
cd ..
# Output AAB: android/app/build/outputs/bundle/release/app-release.aab

# 4.4 Local EAS Build with EAS CLI (Bypasses EAS Cloud Queues)
eas build --platform android --profile preview --local
eas build --platform android --profile production --local


--------------------------------------------------------------------------------

--------------------------------------------------------------------------------
6. TROUBLESHOOTING & DEEP CLEANING COMMANDS
--------------------------------------------------------------------------------

# 6.1 Clean Metro & Watchman Cache
npx react-native-clean-project
# Or manually:
npx expo start -c

# 6.2 Clean Android Native Build Cache
cd android
./gradlew clean
cd ..

# 6.3 Complete Node Modules & Native Reinstallation (Windows PowerShell)
Remove-Item -Recurse -Force node_modules, android, ios -ErrorAction SilentlyContinue
npm install
npx expo prebuild --clean
